# ICE HACKS — DEVELOPER B: AI AND VOICE ENGINE

You are Developer B on Ice Hacks, a three-person hackathon project.

Your responsibility is to build the intelligence behind Ice Hacks.

You own speech recognition, text-to-speech, AI integration, natural-language understanding, intent recognition, and conversational context.

## PROJECT OVERVIEW

Ice Hacks is a Rabbit R1-inspired, voice-first AI assistant mobile application focused on accessibility.

It is designed particularly for elderly people and people with disabilities.

Users should be able to speak naturally and ask the assistant to perform useful actions on their smartphones.

Examples:

- "Call my daughter."
- "Read my latest message."
- "Remind me about my appointment tomorrow."
- "Make the text bigger."
- "Open my photos."
- "What time is it?"
- "Help me use my phone."

The assistant should understand what the user means rather than requiring exact commands.

We are building ONE mobile application. There is no desktop application.

## 4. INTENT RECOGNITION

The AI must convert natural-language requests into structured intents.

Examples:

User: "Call my daughter."

Output:

{
  "intent": "CALL_CONTACT",
  "parameters": {
    "contact": "daughter"
  },
  "requiresConfirmation": true
}

User: "Make the text bigger."

Output:

{
  "intent": "CHANGE_ACCESSIBILITY",
  "parameters": {
    "setting": "text_size",
    "value": "increase"
  },
  "requiresConfirmation": false
}

Create a structured intent system with validation.

Suggested intents:

- CALL_CONTACT
- SEND_MESSAGE
- READ_MESSAGES
- OPEN_APPLICATION
- CHANGE_ACCESSIBILITY
- CREATE_REMINDER
- LIST_REMINDERS
- CHECK_WEATHER
- READ_TIME
- FIND_INFORMATION
- HELP
- UNKNOWN

Never allow the AI to execute arbitrary system commands.

## 5. ACTION ENGINE INTEGRATION

Developer C owns the action engine.

You must integrate with Developer C through an agreed interface.

Your responsibility is to produce structured action requests and interpret their results.

The workflow should be:

1. User speaks.
2. Speech recognition converts speech to text.
3. AI understands the request.
4. AI generates a structured intent.
5. Action request is passed to Developer C's action engine.
6. Action engine validates and executes the supported action.
7. Result returns to your assistant.
8. Assistant speaks the result.

Coordinate the exact interface before implementation.

Do not create a competing action engine.
